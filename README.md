# Neden Otobüs Gelmiyor Simülasyonu

## Dünyanın En Gerçekçi, En Acımasız ve En Gereksiz Yazılımı

Bu depo, insanlığın en eski sorununa çözüm getirmek amacıyla geliştirilmiştir: **Otobüs neden gelmiyor?**

Cevap basit: Çünkü şoför çay içiyor. Veya lastik patlamış. Veya evren sana şaka yapıyor.

### Özellikler
- Gerçekten çalışır.
- Gerçekten hiçbir şeyi değiştirmez.
- Sabır eğitimi verir.
- Çay içme isteğini tetikler.
- Otobüs gelmez. Asla.

### Kullanım
```bash
python otobus_bekleyici.py
```

Çalıştırın. Bekleyin. Hayal kırıklığınızı yaşayın. Sonra yürüyün.

### Lisans
Bu kod, evrenin telif hakkı altındadır. Kopyalayabilirsiniz ama otobüs yine gelmez.

### Katkı
Katkıda bulunmak istiyorsanız, önce otobüsü bekleyin. Gelirse pull request açın. Gelmezse zaten bekliyordunuz.
